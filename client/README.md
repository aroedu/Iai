# אפליקציית הזמנת חדרי ישיבות

## הפעלה

ודאו ששרת ה־API פועל ב־`http://localhost:5128`, ואז הריצו מתוך תיקיית
`client`:

```powershell
npm install
npm start
```

פתחו את `http://localhost:4200`. ה־API מוגדר ב־
`src/app/reservation-api.service.ts`; מדיניות CORS של השרת מאפשרת פיתוח בכתובת
זו.

## יכולות

- בחירת חדר ותאריך, כולל מעבר בין ימים.
- הצגת הזמנות היום לפי שעת התחלה.
- יצירה וביטול של הזמנה.
- הצגת שגיאות ולידציה ושגיאות מהשרת.
